# 硬件学习路线总览

> 这篇是给实验室新人的主线地图。按顺序走，每一阶段都配有对应的文章、资源和实战任务。

## 第一阶段：电子基础（1-2 个月）

- 电路基础：欧姆定律、KCL/KVL、RC/RL 电路、二极管/三极管/MOS 管
- 数字电路基础：逻辑门、组合逻辑、时序逻辑、触发器
- 工具：万用表、示波器、电源、电烙铁
- 实战任务：焊一块最小系统板、点亮 LED、用万用表排查故障

## 第二阶段：单片机入门（2-3 个月）

- 选型：STM32F103 入门，熟悉 CubeMX + HAL 库
- 外设：GPIO、定时器、中断、UART、SPI、I2C、ADC、PWM
- 实战任务：串口打印、按键控制 LED、PWM 调速、I2C 读传感器

## 第三阶段：PCB 设计（1-2 个月）

- 工具：立创EDA（快速上手）/ Altium Designer（进阶）
- 知识：原理图绘制、封装、布局布线、阻抗、电源完整性基础
- 实战任务：画一块自己设计的 STM32 最小系统板并打样焊接

## 第四阶段：进阶方向（按需选择）

- 传感器与信号链：运放、滤波、ADC 采样、IMU 姿态解算
- 电源设计：LDO、DC-DC、电池管理
- 通信：CAN、485、无线（ESP32/蓝牙/NRF）
- RTOS：FreeRTOS 入门
- 电机控制：PWM + 编码器、PID 控制

## 第五阶段：电赛实战（备赛期）

- 熟悉常用模块：电源模块、驱动模块、显示模块、传感器模块
- 学会看数据手册、快速搭建测试电路
- 软硬件联调与排错方法论
